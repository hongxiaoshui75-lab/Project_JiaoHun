## 真实浏览器操作

在仅监听127.0.0.1:4174的本机服务、内置Chromium浏览器执行，未调用游戏内部状态或答案API跳关：

| 场景 | 实际观察 |
|---|---|
| 前情与初次调查 | 点击推进、调查列表、解锁散尾热点、破锁特写、人物选择与独立话题、移动廊下均可用 |
| 图像表现 | 背景、器物、人物差分与特写可加载；无对白的证物调查清除主角立绘，避免挡住物件 |
| 普通会审 | 按钮焦点下ArrowRight切至第二句；错误出示后先反驳与制止，第三句才显示5→4；反馈中刷新仍保留惩罚 |
| 普通失败 | 连续错误举证耗尽威信，进入疑点未明；重试回第一轮入口并恢复5点，再次贯通两轮 |
| 追加查问 | 依次核对索钱、去向、追讨，超凡话题在前置完成后出现，调查条件满足才可推进 |
| 帽子调查 | 外观→后侧下缘→残丝→并排比较；初始不展示剪口；特写在当前对白结束后收起 |
| 最终失败 | 独立5点耗尽后进入真相未尽，明确和尚获释而蔡瑞未被追究；重试回最终首段 |
| 成功 | 帽子、材料记录、去向证言三步举证，持续查究后招供，正确结局保留责打、带枷、最终获释及四僧各得三千二百钱 |
| 原生存档 | 下载JSON成功；改变当前证词后通过文件选择器重新导入，恢复原先进度 |
| 响应式 | 检查1280×720和375×812；375px文档宽度为375，无横向溢出；对白19px，操作可用。手机为浏览器视口模拟，非手机真机 |

上述连续流程检查是按已知测试路线操作，不是无剧本玩家的盲测或艺术认可。查看到成功结局时浏览器错误/警告日志为空。
