# 萧山剪辫案 Demo

此版完成可离线运行的游戏逻辑、剧情数据、存档与AVG图像试玩入口，并提供 NAS v2 的账号、跨设备存档、展示场次与只读观察。正常路线贯通调查、两轮普通举证、三段追加查问、帽子调查、三步最终会审、继续查究及结局。资源含6个场景、8个人物共30张立绘与差分、4张物件原画及5张细节图，共45张选用原图，映射55项运行资源。图片和新增对白均为可校订工作稿，艺术认可仍由用户完成。

## 试玩

直接打开 `../09_Builds/JiaoHun_Demo/Demo.html`，使用现代桌面浏览器，无需联网或安装依赖。部分浏览器对本地文件自动存档有限制，遇到提示时使用 JSON 导出与导入。

也可在本目录运行 `node server.mjs`（Node.js 22+），打开 `http://127.0.0.1:4173`。服务只监听本机。默认端口被占用时，可设置 `JIAOHUN_PORT`。启动脚本位于分发目录的 `Start_Demo.cmd`。

## 开发命令

```powershell
node --test tests/*.test.mjs
node tools/prepare-art.mjs
node tools/build.mjs
```

不需要 `npm install`。prepare-art 重建派生美术副本；build 重建目录包、单文件 HTML 和 ZIP。两者仅清理其明确管理的派生目录。单文件从同一套模块自动内联程序和图像；不要在派生目录存放手写文件或存档备份。

## 规则与扩展

浏览证佐凭据不触发判定；出示必须选择证物后确认。每句证词均有固定追问，重复追问只重播。任意已取得证物可在任意证词提交；不成立时扣1点，反驳与制止播放后才显示威信变化，返回原句。未取得证物及非法动作被拒绝。

普通会审共用5点，最终三段共用独立刷新后的5点。普通失败重试回剪刀回合入口，最终失败回最终首段入口。重试按完整快照恢复，不保留本阶段后续发现。没有倒计时、自动举证或矛盾高亮。

调查中的“获得物件”“检查出细节”“形成比对记录”分别管理。证物说明只随已经发现的事实更新。最终纤维比对不作为唯一来源鉴定，须联系动机与经手经过继续查究。人物只能陈述各自亲历范围。

程序不锁定正式游戏引擎。后续可保留状态机及内容数据，只替换 `web/`，或按接口移植到其他客户端。此版不包含多人、账号、联网数据库、自由生成对白、配音和成品美术。

离线包存档是本地 JSON，校验用于识别损坏与不兼容数据，不提供防作弊保证。NAS v2 使用账号 Cookie 与服务器修订号，并保留本机 pending 作为断网备份；多设备冲突必须手动选择，不自动覆盖。更改剧情阶段或条件后应提升 `content.version`；没有实现旧剧情存档迁移。
